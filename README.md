# libc with c++ features
## what is libc_soduum?
*libc_soduum* is a library for C that adds C implementation of c++ stdlib features, and other advanced tools.
- Linux is the main platform
- standard of C language in code is c23 or newer
- new ideas for features are welcome!
- the goal is to make a cool library for C
